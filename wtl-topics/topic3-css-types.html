WTL Topic 3: The Three Types of CSS

This page clearly demonstrates Inline, Internal, and External CSS for lab evaluation.

1. External CSS

This card's dark background, font family, padding, and subtle shadow are styled by ../style.css via the <link rel="stylesheet"> tag in the head.

2. Internal CSS

This box is styled using rules defined inside the <style> tag in the <head> of this file.

3. Inline CSS

This green container is styled directly on the element using the HTML style="..." attribute.
